# fse2027
Our evaluation includes 70 natural-language testing tasks over 14 real-world Android applications. The applications are grouped into six categories according to their primary functionality. We construct five tasks for each application.

> **Data availability.** Some task details involve sensitive information and are therefore not fully disclosed in this repository. We commit to releasing the complete dataset once the paper is formally published.

| Category | Applications | Tasks |
|---|---|---:|
| Navigation and Local Services | Gaode Map, Meituan, Yelp | 15 |
| Social Networking | Weibo | 5 |
| Media and Entertainment | Bilibili, QQ Music, YouTube, Spotify | 20 |
| E-commerce | Taobao, Temu | 10 |
| Communication and Email | QQ Mail, Telegram, Gmail | 15 |
| System Utilities | Clock | 5 |
| **Total** | **14 applications** | **70** |
